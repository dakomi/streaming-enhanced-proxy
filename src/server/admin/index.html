CA Certificate

Install the local CA certificate on each device so HTTPS interception works without browser warnings.

Setup Guide

Point your browser or router's proxy to this server's IP : 8080.

Installing the CA Certificate

Windows

1. Download ca.crt from the link above.
2. Double-click the file → "Install Certificate"
3. Store Location: Local Machine → Next
4. "Place all certificates in the following store" → Browse → "Trusted Root Certification Authorities"
5. Finish → Yes

macOS

1. Download ca.crt and open it.
2. Keychain Access opens → add to "System" keychain.
3. Find "Streaming Enhanced Proxy CA" → Get Info → Trust → "Always Trust".

Android

1. Download ca.crt to your phone.
2. Settings → Security → Install from storage → select ca.crt.
3. Name it "Streaming Enhanced Proxy CA" → VPN and apps.

iOS / iPadOS

1. Open http://<pi-ip>:3000/ca.crt in Safari.
2. Settings → Profile Downloaded → Install.
3. Settings → General → About → Certificate Trust Settings → enable trust.

Samsung / LG / Vidaa Smart TV

Smart TVs vary by manufacturer. The recommended approach is to configure
your router to intercept traffic at network level, and install the CA on
your router (e.g., OpenWrt: copy ca.crt to /etc/ssl/certs/ and run update-ca-certificates).

Browser Proxy Configuration

HTTP Proxy:  <this-server-ip>:8080
HTTPS Proxy: <this-server-ip>:8080

Router / iptables (Transparent Proxy)

# On the router, redirect HTTP and HTTPS to the proxy:
iptables -t nat -A PREROUTING -p tcp --dport 80  -j DNAT --to <pi-ip>:8080
iptables -t nat -A PREROUTING -p tcp --dport 443 -j DNAT --to <pi-ip>:8080
